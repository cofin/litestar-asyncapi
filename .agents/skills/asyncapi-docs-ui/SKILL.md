# AsyncAPI Documentation Routes & Packaged UI

<!-- truth: start -->
- Reuse native Litestar renderers: `JsonRenderPlugin`, `YamlRenderPlugin`, and `AsyncAPIRenderPlugin` (an alias of `OpenAPIRenderPlugin`). Own only `AsyncAPIUIRenderPlugin` and the bootstrap adapter.
- `create_docs_router` builds one native `Router` with `include_in_schema=False`, `dto=None`, `return_dto=None`, the layered `DocsConfig.guards`/`dependencies`, a static `/assets` router, one named route per renderer, and an HTML/404 fallback.
- Route names come only from `docs.py::renderer_name` (`asyncapi:json`, `asyncapi:yaml`, `asyncapi:playground`, `asyncapi:<Class>`). Links come from `request.url_for`, never string concatenation.
- `DocsConfig.__post_init__` guarantees one JSON renderer, adds YAML only when `yaml=True`, adds `/playground` only when `interactive=True`, and rejects duplicate names, duplicate normalized paths and `/assets` collisions.
- One `AsyncAPIPlugin` binds to one app at first document access. Reuse with another app raises `ImproperlyConfiguredException`, even with `use_cache=False` or after `clear_cache`.
- `get_asyncapi` and `get_asyncapi_schema` return `deepcopy` copies. `get_asyncapi_json` returns immutable bytes. `clear_cache` clears values and keeps the binding.
- Every renderer receives the same normalized schema, produced through `encode_json(..., serializer=get_serializer(app.type_encoders))`.
- HTML attributes and text use `html.escape(..., quote=True)`. Inert bootstrap JSON uses `encode_json` with `<` replaced by `<` inside `<script type="application/json">`. Browser status messages use `textContent`.
- React (AsyncAPI React component 3.2.1, React 18.3.1) is the default. Scalar 1.69.2 is opt-in, renders a limitation notice and refuses `interactive=True`.
- Interaction uses asyncapi-ws-plugin 0.1.0, is opt-in through `DocsConfig.interactive`, never auto-connects, disables URL editing, and validates advisorily: users can send invalid text on purpose. Do not add a second validator or transport.
- The console wraps only JSON-text object/array contracts, including reply messages (`interactive.ts::supportsWire`). Other contracts render a readable note.
- `parse.ts::parseForReact` protects literal `$ref` and own `__proto__` keys from the upstream parser, then restores them. `view.ts::reactView` changes only the React view. Canonical JSON/YAML downloads are untouched.
- Built assets in `src/litestar_asyncapi/assets/ui/` are generated by Vite (`manifest.json`, hashed files, `THIRD-PARTY-LICENSES.md`), committed, and shipped in the wheel and sdist. Consumers need neither Node nor a CDN. Zip imports are unsupported.
- Node 22 is needed only to build and test assets. Python >=3.10, no inline comments in Python, owned classes stay slotted.
<!-- truth: end -->

## Scope

- `src/litestar_asyncapi/plugins/core.py` — `AsyncAPIPlugin`, `_get_document`, `create_docs_router`, `_handle_docs_path_not_found`, `on_app_init`, `on_cli_init`.
- `src/litestar_asyncapi/plugins/renderers.py` — `AsyncAPIUIRenderPlugin`, `AsyncAPIRenderPlugin`, re-exported native renderers.
- `src/litestar_asyncapi/docs.py` — `renderer_name`, `asset_directory`, `bootstrap_html`.
- `src/litestar_asyncapi/config.py::DocsConfig` and `_default_render_plugins`.
- `src/litestar_asyncapi/assets/bootstrap.js` (handwritten, served static) and `assets/ui/**` (Vite output).
- `tools/frontend/{react,scalar,view,parse,interactive}.ts`, `vite.config.ts`, `playwright.config.ts`, `package.json`.
- Tests: `src/tests/unit/test_ui_security.py`, `src/tests/unit/test_json_plugin.py`, `src/tests/unit/plugins/test_playground.py`, `src/tests/integration/test_routes.py`, `src/tests/integration/test_plugin_cache.py`, `tools/frontend/tests/*`.

## Seams

| Role | Boundary |
| --- | --- |
| **Module** | Documentation surface: `AsyncAPIPlugin` + `DocsConfig` + renderers + packaged browser bundle. |
| **Interface** | `AsyncAPIPlugin(config)`, `get_asyncapi`, `get_asyncapi_schema`, `get_asyncapi_json`, `clear_cache`, `create_docs_router`; `DocsConfig(path, enabled, guards, dependencies, renderer, interactive, yaml, render_plugins)`; `AsyncAPIUIRenderPlugin(path, renderer, interactive, role, config)`. |
| **Implementation** | Lazy generation and caching in `_get_document`, route naming, manifest walk in `bootstrap_html`, React/Scalar entry modules. |
| **Seam** | `OpenAPIRenderPlugin.render(request, schema) -> bytes` is the native renderer contract. `route_handler.opt["asyncapi_routes"]` carries the route-name map. `bootstrap.js` loads `#asyncapi-config` and calls `render(schema, options)` exported by each Vite entry. |
| **Adapter** | `AsyncAPIUIRenderPlugin` (native renderer → HTML shell), `parseForReact`/`reactView` (canonical document → React-safe view), `interactivePlugin` (upstream ws plugin → wire-gated operation slot). |

Dependency categories:

1. **In-process** — Litestar `Router`, `create_static_files_router`, `encode_json`/`decode_json`, `url_for`, `AsyncAPIGenerator`. Exercise them directly with `TestClient`/`create_test_client`.
2. **Local-substitutable** — packaged assets on disk and `manifest.json`. Tests point at real built files. Missing-asset behavior renders the `role="alert"` fallback.
3. **Remote-owned (ports & adapters)** — `@asyncapi/react-component`, `@asyncapi/parser`, `@scalar/api-reference`, `asyncapi-ws-plugin`. They are pinned in `package.json` and accessed only through their public APIs from `tools/frontend/*.ts`.
4. **External boundary** — the browser, real WebSocket endpoints and the CSP. Verified with real Chromium in Playwright against `tools/frontend/tests/server.py`, with external network requests aborted. Never mocked inside Python tests.

## Workflow

1. Classify the change: routing/config/cache (Python only), HTML shell/bootstrap (Python + browser), or frontend bundle (TypeScript + rebuild). See [routing-and-cache.md](references/routing-and-cache.md) and [frontend-and-interaction.md](references/frontend-and-interaction.md).
2. Write the focused failing test in the canonical file: routes and guards go in `test_routes.py`, cache and ownership in `test_plugin_cache.py`, escaping in `test_ui_security.py`, console options in `test_playground.py`, view/parser transforms in `tools/frontend/tests/*.test.ts`, and real rendering or interaction in `*.spec.ts`.
3. Implement through the native seam first. Add AsyncAPI-specific code only where the native renderer, router or serializer cannot express the behavior.
4. For any dynamic value reaching HTML, apply `html.escape(..., quote=True)`. For JSON reaching a script element, use `encode_json` and the `<` replacement. Add a hostile-input case to `test_ui_security.py`.
5. For a frontend change, run `make js-build` and commit the regenerated `assets/ui/**` together with the source change. Never hand-edit hashed files or `manifest.json`.
6. Run the verification ladder below, from focused to installed.

## Verification

```bash
uv run pytest src/tests/integration/test_routes.py src/tests/integration/test_plugin_cache.py -q --no-cov
uv run pytest src/tests/unit/test_ui_security.py src/tests/unit/test_json_plugin.py src/tests/unit/plugins -q --no-cov
make slotscheck type-check
make js-install build        # Node 22; npm ci + Vite assets + wheel/sdist + distribution.py asset check
make js-test browser-test    # Vitest + Playwright Chromium; artifacts in .tmp/test-results
make browser-test-installed PYTHON_VERSION=3.12
```

Focused Python runs need `--no-cov`, because the global `--cov-fail-under=80` addopt makes them exit 1 even when the tests pass.
