# API reference

Every name on these pages is importable from `litestar_asyncapi`, `litestar_asyncapi.spec` or the module shown in its heading.

- [Plugin and configuration](plugin.md): `AsyncAPIPlugin`, `AsyncAPIConfig` and `DocsConfig`.
- [Contracts](contracts.md): the decorators, the channel, operation and message definitions, and the transport markers.
- [Generator and discovery](generator.md): `AsyncAPIGenerator` and the WebSocket, Server-Sent Event and ChannelsPlugin extractors.
- [Schema generation](schema.md): the per-document schema generator and the Draft07 export.
- [Renderers](renderers.md): the JSON, YAML and documentation UI render plugins.
- [Specification models](spec/index.md): the AsyncAPI 3.0 and 3.1 objects that make up a document.
- [CLI](cli.md): the `litestar asyncapi export` command.
