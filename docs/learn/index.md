# Learn

Use inferred listener and stream contracts where Litestar knows the payload
shape. Add explicit definitions for raw sockets, external brokers, or metadata
that cannot be inferred from runtime handlers.

- [Installation](installation.md): install the plugin and serve a first document.
- [Concepts and lifecycle](concepts.md): directions, channels, discovery and caching.
- [WebSocket handlers](websocket-handlers.md): listeners, streams, raw sockets and Server-Sent Events.
- [Decorator customization](decorators.md): explicit operations and messages.
- [Schema generation](schema-generation.md): native schemas, the Draft07 dialect and examples.
- [Runnable examples](examples.md): complete applications you can start with the Litestar CLI.

Broker topics, the documentation UI, security and mounting are covered under
[Integrations](../integrations/index.md).
