===============
Getting Started
===============

This guide walks through installing ``litestar-asyncapi`` and generating an AsyncAPI 3.0 specification for a Litestar application.

Installation
============

.. tab-set::

    .. tab-item:: uv

        .. code-block:: bash

            uv add litestar-asyncapi

    .. tab-item:: pip

        .. code-block:: bash

            pip install litestar-asyncapi

Quickstart Application
======================

Register the ``AsyncAPIPlugin`` with your Litestar application. The plugin automatically traverses route handlers, extracts WebSocket operations, generates schemas, and registers documentation endpoints.

.. code-block:: python

    from dataclasses import dataclass
    from litestar import Litestar, websocket_listener
    from litestar_asyncapi import AsyncAPIConfig, AsyncAPIPlugin


    @dataclass
    class ChatMessage:
        user: str
        message: str


    @websocket_listener("/chat")
    async def chat_handler(data: ChatMessage) -> ChatMessage:
        return data


    asyncapi_config = AsyncAPIConfig(
        title="Chat Service",
        version="1.0.0",
        description="Real-time chat service powered by Litestar and AsyncAPI 3.0",
    )

    app = Litestar(
        route_handlers=[chat_handler],
        plugins=[AsyncAPIPlugin(config=asyncapi_config)],
    )

Default Endpoints
=================

When registered, ``AsyncAPIPlugin`` mounts an isolated documentation router with the following default endpoints:

.. list-table::
   :header-rows: 1
   :widths: 35 25 40

   * - Path
     - Content Type
     - Description
   * - ``/asyncapi/``
     - ``text/html``
     - Interactive documentation UI (AsyncAPI UI or Playground)
   * - ``/asyncapi/asyncapi.json``
     - ``application/json``
     - Raw AsyncAPI 3.0 specification in JSON format
   * - ``/asyncapi/asyncapi.yaml``
     - ``application/yaml``
     - Raw AsyncAPI 3.0 specification in YAML format

Core Architecture
=================

The AsyncAPI specification is generated by orchestrating three primary sub-systems:

1. **Route Extraction**: Inspects Litestar route trees to discover WebSocket endpoints, path parameters, and operation direction (send vs. receive).
2. **Schema Registry**: Converts Python type annotations (Msgspec, Pydantic, Attrs, Dataclasses) into AsyncAPI schema components.
3. **Render Plugins**: Renders interactive HTML views and serialized schema documents.
